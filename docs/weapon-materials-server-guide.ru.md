# Применение серверных материалов

[Английская версия](weapon-materials-server-guide.md) | [Справочник API](weapon-materials-server-api.ru.md) | [Руководство автора](weapon-materials-authoring.ru.md)

Для примера нужны AMX Mod X, ReAPI, серверный модуль `NextClientServerApi` и его заголовок `next_client_api`.

## Доставка и привязка материала

1. Создайте пресет по [описанию формата](weapon-materials-server-api.ru.md#формат-пресета) и сохраните его как `materials/my_server/skins.mat`.
2. Проверьте его командой `matgen check <preset.mat> --game <game>/cstrike`.
3. Зарегистрируйте пресет и каждое пользовательское изображение через `ncl_upload_file` в `plugin_precache`. Для файлов `.mat`, `.png` и `.tga` и серверный, и клиентский путь должны находиться внутри `materials/`. Изображения поставляемой коллекции уже установлены с клиентом.
4. Привяжите материал к оружию, затем задайте параметры экземпляра конечными значениями float.

Функция выдает Glock и устанавливает износ `0.65625` в диапазоне `0..1`. Вызывайте ее из логики выдачи предметов плагина.

```pawn
#include <amxmodx>
#include <reapi>
#include <next_client_api>

new const PRESET[] = "materials/my_server/skins.mat";

public plugin_precache()
{
    ncl_upload_file(PRESET, PRESET);
}

public give_golden_glock(id)
{
    new weapon = rg_give_item(id, "weapon_glock18");
    if (weapon <= 0)
    {
        return;
    }

    ncl_mat_bind(weapon, PRESET, "golden_slide");
    ncl_mat_param_all(weapon, "uWear", 0.65625);
}
```

На совместимом клиенте с включенными шейдерами и материалами выданный Glock получает материал `golden_slide` с износом `0.65625`. Имя текстуры в пресете должно совпадать с именем текстуры модели.

## Если материал не отображается

1. Проверьте, что установленный клиент поддерживает это API материалов и использует `r_studio_shader 1` и `r_studio_materials 1`.
2. Проверьте, что пресет получен по тому же относительному пути, который передан в `ncl_mat_bind`.
3. Проверьте имя материала в пресете и имя текстуры модели. Команда `matgen uv <model.mdl>` выводит текстуры модели.
4. Проверьте журнал серверного модуля на ошибки аргументов нативов. Выполните `matgen check <preset.mat> --game <game>/cstrike`, чтобы проверить формат, манифест, пути и изображения.
5. Проверьте привязки загруженного клиента командами из таблицы.

Изменения через `r_mat_bind`, `r_mat_param` и аргументы `r_mat_presets` разрешены только отключенному клиенту. В сетевой игре подкраска и обводка включаются явными серверными параметрами экземпляра `uOccludedAmount` и `uOutlineWidth`, как описано в [эффектах материалов](material-effects.ru.md).

| Команда | Действие |
|---|---|
| `r_mat_presets [file\|clear]` | Вывести пресеты в кеше, загрузить пресет или очистить кеш пресетов и все клиентские привязки материалов. |
| `r_mat_entities` | Вывести индексы и имена моделей из следующих 64 уведомлений об отрисовке сущностей, пропуская повторные индексы. |
| `r_mat_bind` | Вывести привязки; `(never drawn)` отмечает индекс, к которому рендерер не обращался. |
| `r_mat_bind <entity> <preset> <material>` | Применить локальную диагностическую привязку. |
| `r_mat_bind <entity>` | Очистить локальные привязки этого индекса. |
| `r_mat_param <entity> <name\|texture/name> <value>` | Задать параметр экземпляра для всех подходящих материалов или одной указанной текстуры. |

Клиент сохраняет консольные привязки и значения материалов других владельцев при обновлении или удалении синхронизируемого владельца. При обновлении привязок или параметров синхронизируемого владельца его локальные изменения параметров заменяются полным текущим набором синхронизированных значений и значениями по умолчанию. Консольные текстуры занимают места перед синхронизируемыми. При достижении лимита из 16 текстур консольная команда может заменить уже допущенную текстуру, но не добавить новую. Удаление консольной привязки может освободить место для сохраненной синхронизируемой текстуры. Дампы отрисовки и захват изображений описаны в [диагностике Studio](renderer-diagnostics.ru.md).
