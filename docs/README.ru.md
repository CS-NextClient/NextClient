# Документация NextClient

[English version](README.md)

## Тестирование

[Указатель проверок](testing/README.ru.md) содержит ссылки на ручные процедуры, критерии приемки, диагностику, подготовку сервера и автоматические проверки. Он охватывает радар, рендеринг Studio, сцены редактора материалов и монитор производительности.
