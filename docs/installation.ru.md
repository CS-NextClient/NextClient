# Установка и обновление NextClient в Windows

[Английская версия](installation.md) | [Документация](README.ru.md) | [Сборка установщика](tools/installer.ru.md)

Загрузите `NextClient-<tag>-setup.exe` из файлов выпуска. Вместе с ним доступны контрольная сумма `.sha256` и манифест сборки `.manifest.json`. Установщик содержит NextClient и средства установки. Оригинальные файлы Valve берутся из локальной установки Steam. Устанавливать Python отдельно не требуется.

## Новая установка

1. В Steam выберите для Counter-Strike ветку `steam_legacy - Pre-25th Anniversary Build`. NextClient требует движок сборки 8684.
2. Запустите установщик и выберите **New installation from Steam**.
3. Подтвердите найденную папку Half-Life или выберите ее кнопкой Browse. Установщик проверит версию игры до выбора папки назначения.
4. Укажите новую папку вне библиотек Steam. По умолчанию используется `C:\Games\Counter Strike 1.6 NextClient`. Browse открывает системное окно выбора папки Windows и добавляет `Counter Strike 1.6 NextClient` к выбранной родительской папке. При ручном вводе указывается полный путь. Папка назначения не должна существовать.
5. Завершите установку. При необходимости оставьте галочку **Create a desktop shortcut** на последней странице; по умолчанию она установлена. Запустите Steam, затем установленный `cstrike.exe` или его ярлык в меню «Пуск».

Если установщик распознает файлы Anniversary Update, он сообщит о несовместимости и предложит выбрать `steam_legacy`. Для других неизвестных файлов движка или клиента выводится сообщение о неподдерживаемой версии со сведениями о несовпадении SHA-256. Перед повторной попыткой восстановите официальные файлы Steam для поддерживаемой ветки.

Оценка места включает копируемые файлы Steam, пакет NextClient и резерв 64 МБ. Размеры свыше 1024 МБ отображаются в ГБ. На экране проверки отображается обработанный объем подготовленной копии игры. Исходная папка Steam остается без изменений.

## Обновление существующей установки

1. Закройте игру и запустите установщик.
2. Выберите **Update an existing NextClient installation**.
3. Укажите существующую папку игры. Поддерживаются установки из ZIP и через установщик. Browse использует выбранную папку без добавления имени подпапки. Исходная папка Steam в этом режиме не требуется.
4. Завершите установку. Перед обновлением установщик проверит место для заменяемых файлов и резервных копий.

Обновление сохраняет существующие `*.cfg`, `setting_guard.ini` и файлы вне пакета выпуска. Файлы в `platform/defaults` обновляются. Устаревший файл пакета удаляется только при подтверждении, что он относится к прежней установке и не был изменен. Неизвестные файлы в установке из ZIP сохраняются. В режиме обновления галочка создания ярлыка на рабочем столе не предлагается.

## Отмена и восстановление

Во время копирования и обновления файлов доступна кнопка **Cancel**. Подтвердите отмену и дождитесь завершения восстановления. При новой установке подготовленная копия удаляется, при обновлении восстанавливаются прежние файлы.

Сведения об установке, данные восстановления, резервные копии и средства установки находятся в `.nextclient` внутри папки игры. У каждой копии свои данные и регистрация удаления. Резервные копии обновления сохраняются до успешного завершения установки. Прерванная операция восстанавливается перед следующей установкой или обновлением.

Если восстановлению мешает заблокированный файл, закройте удерживающее его приложение и повторно запустите установщик. Восстановление также можно вызвать напрямую:

```powershell
& 'C:\Games\Counter Strike 1.6 NextClient\.nextclient\installer\nextclient-install.exe' recover `
  --destination 'C:\Games\Counter Strike 1.6 NextClient'
```

При ошибке восстановления сохраните указанные в сообщении данные и резервные копии. Установщик не закрывает и не запускает игру.

## Удаление

Запустите `unins000.exe` из корневой папки игры или выберите эту копию в списке установленных приложений Windows. Доступны два режима удаления:

- Сохранение пользовательских файлов, выбранное по умолчанию: удаляются неизмененные файлы, принадлежащие установке. Настройки, измененные файлы, пользовательские карты, демо и посторонние данные сохраняются. Для установки из ZIP учитываются только файлы пакета, примененного установщиком.
- Удаление всей папки игры: удаляется все содержимое, включая пользовательские файлы. Этот режим нужно выбрать явно.

Оба режима сохраняют исходную папку Steam, соседние установки и внешние цели ссылок. При ошибке удаления сведения об установке сохраняются для повторной попытки. Каждая копия имеет собственные ярлыки, которые удаляются вместе с ней.

## Запуск без мастера

Параметр `/DIR` задает полный путь назначения. Для новой установки `/GAMEDIR` указывает исходную папку Half-Life из Steam. Параметр `/STEAMROOT=...` позволяет задать корневую папку для поиска Steam.

```powershell
.\NextClient-v1.2.3-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /MODE=new /GAMEDIR="D:\SteamLibrary\steamapps\common\Half-Life" /DIR="C:\Games\Counter Strike 1.6 NextClient"
.\NextClient-v1.2.3-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /MODE=update /DIR="C:\Games\Counter Strike 1.6 NextClient"
```

Тихая установка не создает ярлык на рабочем столе. При удалении `/REMOVEMODE=preserve` сохраняет пользовательские файлы, а `/REMOVEMODE=full` удаляет всю папку игры. Без этого параметра выбирается сохранение файлов.

```powershell
& 'C:\Games\Counter Strike 1.6 NextClient\unins000.exe' /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /REMOVEMODE=preserve
```
