# Архитектура NextClient

[Английская версия](architecture.md) | [Документация](README.ru.md) | [Настройка сборки](../README.ru.md)

NextClient добавляет функции в Counter-Strike 1.6: изменяет HUD и меню, расширяет рендеринг моделей и предоставляет инструменты для разработки. Игра использует штатный движок Valve. Модули NextClient загружаются вместе с ним и изменяют отдельные части его работы.

## Компоненты

| Компонент | Назначение |
|---|---|
| [nextclient/launcher](../nextclient/launcher/) | Запуск и перезапуск игры, загрузка модулей, обновление клиента в Windows. |
| [nextclient/nitro_api](../nextclient/nitro_api/) | Доступ модулей NextClient к функциям и данным штатного движка и клиента. |
| [nextclient/engine_mini](../nextclient/engine_mini/) | Изменения движка: рендеринг Studio-моделей, материалы, загрузка файлов, монитор производительности. |
| [nextclient/client_mini](../nextclient/client_mini/) | HUD, радар, камера и отображение оружия. |
| [nextclient/gameui](../nextclient/gameui/) | Меню, настройки игры и редактор материалов. |
| [nextclient/filesystem_proxy](../nextclient/filesystem_proxy/) | Работа с файловой системой игры. |
| [nextclient/steam_api_proxy](../nextclient/steam_api_proxy/) | Взаимодействие со Steam. |
| [nextclient/packages](../nextclient/packages/) | Общие библиотеки: математика, обработка изображений, материалы, настройки и фоновые задачи. |
| [nextclient/goldsrc_abi](../nextclient/goldsrc_abi/) | Заголовочные файлы для совместимости со штатными библиотеками GoldSrc. |
| [assets](../assets/) | Ресурсы интерфейса, локализация, шейдеры и материалы, устанавливаемые вместе с клиентом. |
| [installer](../installer/) | Установка, обновление, восстановление и удаление отдельных копий игры в Windows. |
| [tools](../tools/) | Утилиты для подготовки ресурсов, упаковки выпусков, запуска тестового сервера и проверки результатов. |
| [test_support](../test_support/) | Плагины тестового сервера и библиотеки для запуска тестов. |

`client_mini` и `gameui` используют возможности `engine_mini`. Например, GameUI показывает редактор материалов, а `engine_mini` рисует модель в его окне. Обращение к штатному движку выполняется через `nitro_api`. Код, нужный нескольким модулям, находится в `packages`.
