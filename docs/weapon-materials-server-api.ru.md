# Серверное API материалов

[Английская версия](weapon-materials-server-api.md) | [Серверное руководство](weapon-materials-server-guide.ru.md) | [Формат материалов](weapon-materials.ru.md)

Модуль `NextClientServerApi` позволяет плагинам AMX Mod X назначать материалы игровым сущностям. Для назначения нужны сущность, путь к пресету и имя материала в нем. Доступные плагину функции Pawn называются нативами и перечислены ниже. Файлы пресетов и изображений передаются клиенту через загрузку приватных ресурсов. Сервер отдельно передает назначения и значения параметров для каждой сущности. Для отображения материалов нужны `r_studio_shader 1` и `r_studio_materials 1`.

## Нативы

Нативы возвращают `1` при успехе или `0` при ошибке. Неверные аргументы отмечаются в журнале серверного модуля. `ncl_mat_unbind` также возвращает `0`, если указанной привязки нет.

| Функция | Назначение |
|---|---|
| `ncl_mat_bind` | Привязать указанный материал пресета. Новая привязка заменяет отрисовываемый материал той же текстуры. Повторная привязка уже существующей пары пресета и материала сохраняет ее состояние. Заданные значения параметров экземпляра продолжают действовать. |
| `ncl_mat_unbind` | Удалить привязку указанного материала пресета. |
| `ncl_mat_clear` | Удалить материалы сущности и прекратить синхронизацию ее материалов. |
| `ncl_mat_param` | Задать скалярный параметр экземпляра для материала, выбранного по имени текстуры модели. |
| `ncl_mat_param_all` | Задать скалярный параметр экземпляра для всех привязанных материалов, которые его объявляют. |
| `ncl_mat_through_walls` | Явно разрешает передачу привязанной сущности вне PVS готовым клиентам NextClient 2.6+. Отключение возвращает синхронизацию материалов по PAS. См. [эффекты](material-effects.ru.md#управление-с-сервера). |

Материал можно назначить серверной сущности. Для оружия Counter-Strike назначение сохраняется при подборе и выбрасывании. Когда игрок держит оружие, материал виден на модели от первого лица и на носимой модели `p_`. После выбрасывания он виден на модели лежащего оружия.

Материал применяется ко всем частям модели с указанным именем текстуры. Клиент получает актуальные назначения при подключении и когда сервер снова начинает передавать ему данные об этой сущности. Удаление одного материала не удаляет остальные. Если несколько назначений относятся к одной текстуре, проверьте выбранный материал [диагностическими командами](weapon-materials-server-guide.ru.md#если-материал-не-отображается).

Параметры экземпляра задаются отдельно для каждой сущности: например, одинаковый материал двух оружий может иметь разную степень износа. Допускаются конечные числовые значения в единицах и диапазоне параметра. Параметры выбора принимают только целые индексы. При недопустимом значении сохраняется предыдущее. Удаление параметра возвращает значение пресета; удаление серверного параметра подкраски или обводки отключает соответствующий эффект.

| Параметр `weapon_finish` | Диапазон |
|---|---|
| `uWear` | `0..1` |
| `uLayerMix` | `0..1` |

Используйте согласованные версии клиента и серверного модуля. Подключающиеся игроки и игроки, возвращающиеся в область обновления, должны получать текущие назначения материалов. После изменения любой стороны проверяйте результат в игре.

## Формат пресета

```json
{
    "version": 1,
    "materials": [
        {
            "name": "golden_slide",
            "texture": "glock_slide.bmp",
            "material": {
                "program": "weapon_finish",
                "params": {
                    "uWearMap": { "texture": "materials/masks/wear/blotches.png" },
                    "uWearMapTransform": [8.0, 8.0, 0.0, 0.0],
                    "uUnderlay": { "texture": "materials/surfaces/brass.png" },
                    "uUnderlayTint": [1.0, 0.55, 0.1, 1.0],
                    "uWear": 0.5
                }
            }
        }
    ]
}
```

Поле `name` уникально внутри файла и сравнивается без учета регистра. Поле `texture` задает имя текстуры модели. Объект `material` использует ту же структуру программы и параметров, что и документ модели. При создании привязки используются значения параметров из пресета. Затем к ним применяются значения, заданные для конкретной сущности.

Сущность может отображать материалы не более чем на 16 разных текстурах. Если этот лимит или перекрывающиеся назначения скрывают ожидаемый материал, проверьте и упростите действующие привязки перед сравнением изображения.

## Проверка и ограничения клиента

| Ресурс | Лимит |
|---|---|
| Версия пресета | `1` |
| Материалы одного пресета | 128 |
| Различные файлы изображений, указанные в пресете | 64, включая поставляемые изображения |
| Путь изображения | 96 байт |
| Путь файла пресета | 128 байт, относительный путь с расширением `.mat` |
| Размер файла пресета | 1 МиБ |
| Пресеты в кеше | 32, включая записи неудачных загрузок, до очистки кеша |
| Разные текстуры с материалами у одной отрисовываемой сущности | 16 |

Неверная структура, повтор имен, недопустимые пути изображений и превышение лимитов файла приводят к отклонению всего пресета. Пути изображений должны соответствовать [правилам формата материалов](weapon-materials.ru.md#ограничения-файлов-и-изображений). Если программа неизвестна или материал не проходит проверку по манифесту, удаляется этот материал, а допустимые записи сохраняются. При загрузке изображений проверяются данные PNG/TGA и площадь, не превышающая 1 048 576 пикселей.

Для моделей игроков используйте исходное имя текстуры, например `DM_Base.bmp`. Перекраска цветов команды остается доступной. Программа `weapon_finish` также применима к другим Studio-моделям помимо оружия.
