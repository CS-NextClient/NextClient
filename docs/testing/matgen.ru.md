# Регрессионные проверки matgen

[English version](matgen.md)

Соберите `matgen`, затем запустите три отдельных теста ниже через Python 3, указав путь к исполняемому файлу. Каждый тест использует только стандартную библиотеку Python, создает модели во временном каталоге и удаляет результаты после завершения.

```text
python tools/matgen/tests/repeat_test.py out/bin/Release/matgen.exe
python tools/matgen/tests/reference_pose_test.py out/bin/Release/matgen.exe
python tools/matgen/tests/output_collision_test.py out/bin/Release/matgen.exe
```

Тест повторения текстуры проверяет покрытие UV и карты износа на горизонтальных и вертикальных границах повторения, барицентрическую интерполяцию, отрицательные координаты, неизменность результата при сдвиге на целое число тайлов и тонкие треугольники с предельными UV типа signed short, включая исходную текстуру размером в один пиксель. Отдельный случай использует текстуру 2x2 и полный диапазон signed short для карты 2048x2048, чтобы проверить объем вычислений при многократном повторении текстуры. В каждом тесте отдельный запуск `matgen` ограничен 30 секундами.

Тест опорной позы сравнивает пиксели карт для одинаковой геометрии в системе координат модели. Варианты используют перенос костей, поворот, иерархию родителей и независимые кости позиций и нормалей. Каждый результат должен точно совпадать с изображением модели без преобразований костей. Также проверяются имена выходных файлов UV и карт износа: обычные имена текстур, имена с недопустимыми символами и пустые имена.

Тест конфликтов имен выходных файлов создает две записи текстур с отдельными мешами и привязками скинов. Он проверяет замену недопустимых символов, регистр ASCII, пустые имена и пропуск неиспользуемых текстур при запекании кромок. При конфликте имен команда должна явно сообщить об ошибке до замены существующего файла или записи другого PNG. Две карты кромок с разными именами должны содержать геометрию.
