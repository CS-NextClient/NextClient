# Тестирование NextClient

[English version](README.md) | [Вся документация](../README.ru.md)

Для результата следует записать ревизию исходного кода, конфигурацию сборки, установленные файлы, выбранный сценарий и результат проверки. Успешные результаты остаются действительными для тех же исходных файлов и конфигурации. Повторная проверка требуется при изменении соответствующего поведения или при конкретном сомнении, которое нужно разрешить.
