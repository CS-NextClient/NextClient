# Эффекты материалов

[Английская версия](material-effects.md) | [Формат материалов](weapon-materials.ru.md) | [Серверный API](weapon-materials-server-api.ru.md)

Материалы `studio` и `weapon_finish` поддерживают одинаковые эффекты прозрачности и отображения за стенами. Выберите нужную программу в редакторе материалов. Во вкладке освещения галочка «Показать тестовую преграду» включает панель, которая записывает глубину и перекрывает левую часть окна сцены. Compare отключает эффекты материала и сохраняет настройки сцены. Редактор открывается из меню разработчика или командой `r_mat_panel`.

Общее поведение объявлено встроенным контрактом рендеринга `studio_effects_v1`. Рендерер определяет семантические роли и допустимые декларации; универсальные параметры манифеста не дают доступа к эффектам. [Формат материалов](weapon-materials.ru.md#манифест-программы) описывает допуск и значения по умолчанию.

## Растворение и шумовая прозрачность

| Параметр | Назначение |
|---|---|
| `uDissolveMap` | Порог растворения в красном канале изображения. Без изображения используется белый цвет. |
| `uDissolveTransform` | `[масштаб_x, масштаб_y, сдвиг_x, сдвиг_y]`. |
| `uDissolveSpace` | `0`: UV поверхности; `1`: координаты окна сцены. |
| `uDissolve` | `0..1`. Ноль сохраняет все фрагменты; единица полностью скрывает поверхность. Промежуточные значения скрывают фрагменты, у которых значение маски не превышает заданный порог. |
| `uNoise` | Процедурная прозрачность `0..1`. Ноль сохраняет поверхность; единица полностью скрывает ее. |
| `uNoiseSpace` | `0`: UV поверхности; `1`: координаты окна сцены. |
| `uNoiseScale` | Число ячеек шума на единицу координат, `1..1024`, по умолчанию `256`. |
| `uNoiseSeed` | Воспроизводимый вариант рисунка, `0..32767`. |
| `uNoiseSpeed` | Число обновлений рисунка в секунду, `0..60`. Ноль фиксирует рисунок. |

Начало экранных координат находится в левом нижнем углу окна сцены. Обе оси делятся на его высоту. Одна единица соответствует высоте окна, поэтому ячейки шума остаются квадратными при любом соотношении сторон. Экранный рисунок сохраняет положение при движении модели. UV-рисунок движется вместе с поверхностью. Растворение и шум используют независимые системы координат. Сохраняются только фрагменты, прошедшие оба условия. Отверстия маскированной базовой текстуры остаются прозрачными.

Шум изменяет видимость фрагментов поверхности. Его рисунок зависит от начального значения генератора (`uNoiseSeed`) и сохраненного времени рендеринга. Поверхность, эффекты за стенами и выбор мышью используют одинаковые условия видимости. Документ материала допускает до 64 параметров, включая значения по умолчанию из манифеста.

## Деформация геометрии и разделение RGB

Глитч смещает вершины модели по горизонтали в пикселях окна сцены и разделяет красный и синий каналы базовой текстуры. Рисунок задают горизонтальные полосы, сохраненное время рендеринга и начальное значение генератора (`uGlitchSeed`). Эффект действует на выбранный материал. Геометрия, выбор мышью и эффекты за стенами используют одно преобразование. Альфа-канал исходной текстуры, растворение и шум сохраняют свое действие. Нулевая интенсивность отключает обе части эффекта. Нулевая скорость останавливает рисунок. У моделей с редкой сеткой меньше вершин для деформации.

| Параметр | Диапазон | По умолчанию |
|---|---|---|
| `uGlitchAmount` | `0..1` | `0` |
| `uGlitchDisplacement` | `0..64` пикселя | `12` |
| `uGlitchBands` | `1..128` полос на высоту окна | `24` |
| `uGlitchRgbSplit` | `0..16` пикселей | `2` |
| `uGlitchSpeed` | `0..60` изменений рисунка в секунду | `12` |
| `uGlitchSeed` | `0..32767` | `0` |

В [примерах KinoGlitch](https://github.com/keijiro/KinoGlitch) показаны дрожание строк, смещение цветовых каналов и блочные искажения. [Пример для 3D-моделей](https://github.com/callumSharman/glitch-shader) сочетает деформацию геометрии с разделением RGB. Они использованы как визуальные ориентиры.

## Редактирование группы текстур

Нажмите **Группа** рядом с полем текстуры, отметьте нужные текстуры или нажмите **Выбрать все**, затем **Применить**. Редактор показывает значения первой выбранной текстуры. Звездочка отмечает параметр, значения которого в группе различаются. Изменение этого параметра применяется ко всем выбранным текстурам. Остальные параметры сохраняют свои значения. Если в группе разные шейдеры, поле программы показывает **Разные шейдеры**. Для изменения параметров сначала выберите общую программу.

Сохранение записывает все выбранные текстуры вместе и сохраняет остальные записи документа модели. Группа переносится на связанную модель только при наличии всех выбранных имен текстур. Сравнение действует на всю группу. Выбор одной текстуры возвращает одиночное редактирование с обычным подтверждением несохраненных изменений.

## Подкраска, обводка и свечение

| Параметр | Назначение |
|---|---|
| `uOccludedAmount` | Интенсивность подкраски `0..1`, по умолчанию `0`. |
| `uOccludedColor` | Цвет подкраски RGBA. |
| `uOutlineMode` | `0`: только скрытая часть силуэта (по умолчанию); `1`: весь силуэт; `2`: только видимая часть силуэта. Свечение использует тот же режим. |
| `uOutlineWidth` | Ширина внешней обводки в пикселях, `0..16`, по умолчанию `0`. Ноль также отключает свечение. |
| `uOutlineColor` | Цвет обводки и свечения RGBA. |
| `uGlowRadius` | Дополнительный радиус мягкого свечения в пикселях, `0..64`, по умолчанию `8`. |
| `uGlowStrength` | Интенсивность свечения `0..4`, по умолчанию `0`. |

На вкладке «Материал» выберите **Режим обводки**. Значение **Только за преградой** обводит скрытую часть внешнего силуэта, а **Всегда** обводит весь внешний силуэт независимо от препятствий. Значение **Только видимые** обводит только видимую часть внешнего силуэта. Режим действует на обводку и свечение. Подкраска остается только на скрытых пикселях. Линия пересечения модели со стеной не создает дополнительную обводку. Растворение, шум и альфа-канал маскированной текстуры действуют во всех трех режимах.

Рендерер сравнивает ближайшую поверхность модели с глубиной готовой сцены. При MSAA оба буфера глубины сохраняют одинаковое число сэмплов, а сравнение выполняется отдельно для соответствующих отсчетов. Пиксель считается скрытым, только если скрыты все его сэмплы, покрытые моделью. Видимая поверхность сохраняет свой материал. Внешнее свечение не накладывается на пиксели, покрытые сэмплами модели.

Маски строятся, пока доступны исходные текстуры и поза модели. Обычные части выбранной модели тоже записывают глубину и закрывают ее задние поверхности. Серверные привязки и локальные материалы присоединенного оружия позволяют определить затронутую сущность до отрисовки основной модели. Размер маски ограничивается проекцией консервативных границ костей с запасом на радиус эффекта и максимальное смещение глитча. Поиск границы и наложение эффекта выполняются полноэкранными проходами по всему окну с проверкой границ сохраненной маски. При пересечении ближней плоскости используется все окно. Между кадрами кэш хранит маски общей площадью до 512 × 1024 пикселей. Команда `r_mat_scene_state` выводит показатели последнего вида с эффектами: число сущностей и захваченных пакетов, площадь масок, число повторно использованных буферов, формат глубины и число сэмплов. Команда `r_preview_state` выводит те же показатели во время игры.

Редактор материалов рисует сцену, эффекты материала, выбор текстуры и гизмо солнца в отдельном буфере кадра. Затем цвет и глубина переносятся в окно с учетом области отсечения. Буфер сцены сохраняет форматы цвета и глубины, а также число сэмплов исходного буфера. Геометрия сцены и глубина маски проходят одинаковый внеэкранный рендеринг.

## Управление с сервера

В сетевой игре значения `uOccludedAmount` и `uOutlineWidth` задаются только явными вызовами `ncl_mat_param_all` или `ncl_mat_param` на сервере. Синхронизированная привязка начинает работу с нулевыми значениями независимо от содержимого пресета; удаление серверного параметра снова отключает соответствующий эффект. Локальные документы моделей и консольные привязки не включают подкраску или обводку. Команды изменения материалов доступны только отключенному клиенту. В редакторе главного меню доступны все эффекты. `ncl_mat_through_walls` отдельно разрешает передачу сущности вне PVS.

Создайте пресет с нужным именем текстуры модели, передайте его штатным API приватной загрузки и привяжите через `ncl_mat_bind`. Следующий набор параметров включает оранжевую подкраску и обводку:

```json
{
    "program": "studio",
    "params": {
        "uOccludedAmount": 0.5,
        "uOccludedColor": [1.0, 0.25, 0.05, 0.7],
        "uOutlineWidth": 2.0,
        "uOutlineColor": [1.0, 0.5, 0.1, 1.0],
        "uGlowRadius": 8.0,
        "uGlowStrength": 1.0
    }
}
```

После привязки явно разрешите передачу сущности вне PVS, потенциально видимой области карты:

```pawn
ncl_mat_bind(entity, "materials/presets/effects.mat", "highlight");
ncl_mat_through_walls(entity, true);
ncl_mat_param_all(entity, "uOccludedAmount", 0.5);
ncl_mat_param_all(entity, "uOutlineWidth", 2.0);
ncl_mat_param_all(entity, "uOutlineMode", 2.0);
ncl_mat_param_all(entity, "uGlowStrength", 1.0);
ncl_mat_param_all(entity, "uDissolve", 0.25);
ncl_mat_param_all(entity, "uNoise", 0.5);
ncl_mat_param_all(entity, "uNoiseSpeed", 4.0);
```

Разрешение передачи требует действующей привязки материала. Оно применяется к готовым клиентам NextClient 2.6+ и следует за отображаемым владельцем при подборе и выбрасывании оружия. При включении привязка материала передается всем подходящим клиентам, а при отключении снова используется PAS. Очистка, снятие последней привязки, повторное использование исходной сущности или владельца и смена карты отзывают разрешение. Обычные клиенты сохраняют штатные правила видимости. Правила GameDLL для no-draw, отсутствующей модели, наблюдателей и групп сохраняют силу. Передача также ограничена вместимостью пакета сущностей движка. После отключения штатный кэш видимости GameDLL может ненадолго сохранять недавно видимую сущность. Реализация сохраняет [построение состояния и проверки GameDLL](https://github.com/rehlds/ReGameDLL_CS/blob/master/regamedll/dlls/client.cpp).

| Параметр экземпляра | Диапазон значений |
|---|---|
| `uDissolve`, `uNoise`, `uOccludedAmount` | `0..1` |
| `uNoiseSeed` | `0..32767` |
| `uNoiseSpeed` | `0..60` изменений в секунду |
| `uOutlineWidth` | `0..16` пикселей |
| `uOutlineMode` | Целые индексы `0`, `1`, `2` |
| `uGlowStrength` | `0..4` |

Системы координат, преобразование маски, цвета, плотность шума и радиус свечения задаются в пресете. Параметры экземпляра передаются как конечные float в указанных единицах. Обычные скаляры сохраняют точность float. `uOutlineMode` требует целого индекса, например `2.0` в Pawn. Дробные индексы отклоняются до ограничения границами. На сервере нужны обновленный модуль и Pawn include. Одна установка клиентских DLL не включает передачу вне PVS.

Тестовый плагин, его ресурсы и команды проверки находятся в [test_support/plugins/nextclient_materials_test](testing/materials-test-plugin.ru.md).
