# Сборка установщика для Windows

[Английская версия](installer.md) | [Установка и обновление игры](../installation.ru.md) | [Проверка установщика](../testing/installer.ru.md)

Скрипт `tools/installer/build_installer.ps1` создает установщик из готового пакета NextClient для Windows x86 Release. Пакет содержит собранные модули клиента и ресурсы. Результат сборки: EXE, файл контрольной суммы SHA-256 и манифест со сведениями об исходниках и составе пакета.

## Требования

- Windows и Git.
- Windows PowerShell 5.1 или PowerShell 7 с политикой выполнения, разрешающей запуск локальных скриптов, например `RemoteSigned`.
- Готовый пакет NextClient для Windows x86 Release.
- Доступ к источникам загрузки Python, Inno Setup и зависимостей Python либо заранее подготовленный кеш инструментов и зависимостей.

### Подготовка пакета

Подготовьте отдельную папку, например `<репозиторий>\install`, по [инструкции сборки клиента](../building.ru.md). Задайте абсолютный путь к этой папке в `NEXTCLIENT_INSTALL_DIR` и соберите цель `BUILD_ALL` с отключенными тестами (`NEXTCLIENT_BUILD_TESTS=OFF`). Цель скопирует в нее модули клиента и все файлы `assets/`.

Модули, ресурсы и скрипты установщика должны соответствовать одному состоянию исходников. Файлы оригинальной игры установщик получает из копии Steam при установке NextClient.

### Инструменты сборки

Скрипт автоматически подготавливает Python 3.12.10 x86, зависимости из [`installer/requirements-build.txt`](../../installer/requirements-build.txt) и Inno Setup 6.7.3. При загрузке Python и Inno Setup скрипт сверяет их контрольные суммы SHA-256. Инструменты и виртуальная среда Python сохраняются в `build/installer-tools`.

Параметры `-Python` и `-Iscc` позволяют использовать установленные инструменты. Для Python требуется версия 3.12 с архитектурой x86.

## Упаковка и проверка

После подготовки пакета выполните из корня репозитория:

```powershell
.\tools\installer\build_installer.ps1 -Payload install -Version 2.6.0-preview.1 -SmokeTest
```

Скрипт проверяет состав пакета, подготавливает инструменты, запускает модульные тесты и собирает установщик. Параметр `-SmokeTest` дополнительно запускает проверку собранной служебной программы установки через отдельный установщик с синтетическими файлами игры. Порядок проверки и ожидаемые результаты описаны в [процедуре проверки установщика](../testing/installer.ru.md).

При успешном завершении скрипт выводит пути к EXE, файлу контрольной суммы и манифесту. С параметром `-SmokeTest` он также выводит папку журналов `build/installer-smoke/<идентификатор>`.

Для пакета вне репозитория или другой папки результата укажите пути явно:

```powershell
.\tools\installer\build_installer.ps1 -Payload "D:\Artifacts\NextClient" -Output "D:\Artifacts\Installer" -SmokeTest
```

Относительные пути в параметрах отсчитываются от корня репозитория.

## Параметры

| Параметр | Назначение и значение по умолчанию |
|---|---|
| `-Payload` | Папка готового пакета Windows x86 Release. По умолчанию `install`. |
| `-Version` | Версия установщика, например `2.6.0-preview.1` или `v1.2.3`. По умолчанию версия проекта из CMake с суффиксом `-local.<первые восемь символов идентификатора коммита>`. |
| `-Output` | Папка для результатов сборки. По умолчанию `out/installer/<версия>`. |
| `-ToolsDirectory` | Папка инструментов и виртуальной среды Python. По умолчанию `build/installer-tools`. |
| `-Python` | Путь к исполняемому файлу Python 3.12 x86. При отсутствии параметра скрипт подготавливает Python автоматически. |
| `-Iscc` | Путь к компилятору Inno Setup `ISCC.exe`. При отсутствии параметра скрипт подготавливает Inno Setup автоматически. |
| `-SkipTests` | Пропускает модульные тесты. Используйте, если они уже прошли для того же состояния затронутых исходников, зависимостей и конфигурации. |
| `-SmokeTest` | После сборки проверяет служебную программу установки через отдельный установщик с синтетическими файлами игры и выводит папку журналов. |
| `-Help` | Выводит справку по скрипту. |

## Проверка результата

Выходная папка содержит:

| Файл | Назначение |
|---|---|
| `NextClient-<версия>-setup.exe` | Установщик для распространения среди игроков. |
| `NextClient-<версия>-setup.sha256` | Контрольная сумма SHA-256 файла EXE. |
| `NextClient-<версия>-setup.manifest.json` | Идентификатор коммита, наличие изменений в рабочей папке репозитория, платформа и конфигурация сборки, версии Python и PyInstaller, состав пакета, пути файлов, их размеры и контрольные суммы. |

Перед распространением проверьте, что манифест указывает ожидаемые исходники и пакет. Вычислите SHA-256 файла EXE и сверьте его со значением в файле `.sha256`.

При ошибке состава пакета проверьте перечисленные в сообщении отсутствующие и лишние файлы. Ошибка формата бинарного файла означает, что требуется корректный файл Windows x86 PE32. Если найден указатель Git LFS, загрузите ресурсы командой `git lfs pull` и заново подготовьте пакет через `BUILD_ALL`. Повторите упаковку после устранения указанной причины.

## Сборка при публикации выпуска

При публикации выпуска в GitHub [процесс выпуска](../../.github/workflows/release.yml) запускает сборку клиента. Затем задача установщика получает пакет Windows `NextClient-${{ github.sha }}`, собирает установщик и выполняет его проверки.

После успешного завершения сборки клиента и проверок установщика задача публикации добавляет EXE, контрольную сумму и манифест к файлам выпуска вместе с архивами клиента. Для этих файлов создается подписанное подтверждение происхождения сборки. Журналы проверки сохраняются отдельно от файлов выпуска. Ошибка проверки установщика блокирует публикацию файлов выпуска.
