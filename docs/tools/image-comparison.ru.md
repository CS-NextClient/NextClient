# Сравнение изображений рендеринга

[Английская версия](image-comparison.md)

`imgdiff.py` сравнивает подготовленные эталонное и проверяемое изображения с допуском для каждого пикселя. Для работы нужны Python, NumPy и Pillow. Поддерживаются форматы изображений, которые читает установленный Pillow, в том числе PNG и TGA. Скрипт сравнивает значения RGB.

Для снимков радара подготовьте сцены с плагином TestLab по [процедуре ручного тестирования](../testing/manual-testing.ru.md) и [перечню сценариев](../testing/manual-testing-scenarios.ru.md).

## Сравнение изображений

1. Подготовьте эталон и проверяемый снимок одной неподвижной сцены при одинаковом разрешении и графических настройках. Вместе с эталонами сохраните сведения о GPU и драйвере.
2. Из корня репозитория запустите сравнение, указав пути к подготовленным файлам:

```text
python tools/radar_tests/imgdiff.py "<captures>/golden.tga" "<captures>/check.tga" --out diff.png
```

Замените `<captures>` каталогом с изображениями. Размеры двух изображений должны совпадать. Параметр `--out` сохраняет тепловую карту сравниваемого изображения или выбранной области. Обновляйте эталоны после намеренного изменения рендеринга или оборудования.

## Допуски и область сравнения

Для каждого пикселя скрипт берет наибольшую абсолютную разницу его RGB-компонентов. Пиксель считается различающимся, если это значение превышает `--tol`. По умолчанию допуск равен `12`. Сравнение проходит, если доля различающихся пикселей не превышает `--fail-frac`. Значение `--fail-frac` по умолчанию равно `0.002` (0,2%). Несовпадение размеров дает неуспешный результат.

Параметр `--region X,Y,W,H` ограничивает сравнение прямоугольником, координаты которого отсчитываются от левого верхнего угла изображения. Координаты начала должны быть неотрицательными, ширина и высота положительными. Прямоугольник должен целиком помещаться в обоих изображениях.

## Проверка сосредоточенных различий

```text
python tools/radar_tests/imgdiff.py "<captures>/golden.tga" "<captures>/check.tga" --clusters --out diff.png
```

Параметр `--clusters` объединяет соседние плитки, плотно заполненные различающимися пикселями. Если в группе достаточно таких пикселей и средние изменения их RGB-компонентов направлены преимущественно в одну сторону, сравнение также завершается неуспешно. Это условие проверяется и при допустимой общей доле различий.

| Параметр | По умолчанию | Значение |
|---|---|---|
| `--cluster-tile` | `16` | Сторона плитки в пикселях. |
| `--cluster-density` | `0.15` | Минимальная доля различающихся пикселей для плотной плитки. |
| `--cluster-min` | `64` | Минимальное число различающихся пикселей для отклонения группы. |
| `--cluster-bias` | `0.6` | Минимальное абсолютное отношение знаковой суммы средних изменений RGB к сумме их модулей для отклонения группы. |
| `--cluster-list` | `10` | Максимальное число групп в отчете. |

Проверьте каждую указанную область и причину ее изменения. На изображение влияют анимация, движение, освещение, точность вычислений и ошибки рендеринга. Храните снимки, тепловую карту и вывод сравнения вместе.

## Коды завершения

| Код | Значение |
|---|---|
| `0` | Все включенные критерии сравнения пройдены. |
| `1` | Не пройдено сравнение пикселей, размеров изображений или групп различий. |
| `2` | Неверные аргументы, отсутствующие зависимости, недопустимая область или ошибка чтения либо записи изображения. |
