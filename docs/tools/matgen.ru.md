# matgen

[Английская версия](matgen.md) | [Руководство автора](../weapon-materials-authoring.ru.md) | [Формат материалов](../weapon-materials.ru.md)

`matgen` экспортирует UV-шаблоны моделей, проверяет файлы материалов и запекает карты износа по геометрии модели. Утилита использует библиотеки `ncl_material` и `ncl_studio` и работает вне игрового движка.

## Сборка

Выберите пресет из `CMakePresets.json`, подходящий для установленных инструментов сборки. Для Ninja с MSVC сначала инициализируйте окружение компилятора x86.

```text
cmake --preset ninja
cmake --build --preset ninja-debug --target matgen
```

Стандартный путь результата в Windows: `out/bin/Debug/matgen.exe`. Расположение зависит от выбранной конфигурации и настроек CMake. В командах ниже замените `matgen` путем к собранному исполняемому файлу, если его каталог не добавлен в `PATH`.

## Экспорт UV-шаблонов

```text
matgen uv <model.mdl> [--out <dir>] [--size <pixels>] [--skin <family>]
```

Команда создает PNG с проволочной разверткой для каждой записи текстуры модели. Параметр `--skin` выбирает семейство, по которому треугольники мешей распределяются между текстурами. Для неиспользуемых текстур создаются пустые шаблоны. По умолчанию выбрано семейство `0`.

Без `--size` за основу берутся размеры исходной текстуры. Параметр `--size` задает масштаб по длинной стороне. Затем каждая сторона ограничивается диапазоном `64..2048` пикселей, поэтому на границах пропорции могут измениться. Файлы сохраняются рядом с моделью, если не задан `--out`.

Линии UV-развертки переходят через границы повторения текстуры с сохранением геометрии каждого треугольника. Утилита выводит число треугольников, сдвинутых на целое число повторов текстуры. Используйте полученные имена текстур при указании материалов.

В именах выходных файлов сохраняются латинские буквы ASCII, цифры, `_` и `-`; остальные символы заменяются на `_`. Для пустого имени UV-экспорт использует `texture`. Перед записью изображений утилита проверяет совпадения полученных имен без учета регистра ASCII, в том числе для Windows. При таком совпадении команда завершается с ошибкой, а существующие файлы сохраняются.

## Проверка документа или пресета

```text
matgen check <file.mat> [--game <dir>]
```

Команда определяет документ модели или серверный пресет по структуре, разбирает его и проверяет материалы по встроенным манифестам программ. Также проверяются пути изображений, наличие файлов, метаданные PNG/TGA и лимит площади в 1 048 576 пикселей. Лимит применяется к произведению `width * height`. Изображения ищутся в каталоге из `--game` по путям, указанным в материале. Если `--game` не задан, используется текущий каталог. Код завершения `1` означает ошибку, `0` означает успешное прохождение перечисленных проверок.

Утилита использует те же файлы манифестов, что и движок. Выделение GL-ресурсов, полное декодирование изображений, пользовательские шейдерные программы и доставка файлов с сервера требуют отдельной проверки в соответствующих компонентах.

## Запекание износа кромок

```text
matgen bake edges <model.mdl> [--out <dir>] [--size <pixels>] [--skin <family>]
```

Команда запекает пороговую карту износа по геометрии модели для каждой текстуры, которую используют треугольники выбранного семейства скинов. Неиспользуемые текстуры пропускаются. Пустому имени текстуры соответствует файл `_edges.png`. Проверка совпадений учитывает только изображения, которые будут записаны. Выпуклые участки стираются раньше. Кривизна нормализуется по распределению значений самой модели. Изображение заполняется и за краями UV-островов, чтобы уменьшить швы при фильтрации. Укажите полученную карту в `uWearMap`.

Кривизна рассчитывается в опорной позе, которую задают значения костей по умолчанию и их иерархия. Перед объединением вершин позиции и нормали переводятся в систему координат модели по собственным индексам костей. Для нормалей применяется только поворот. Карта износа соответствует этой фиксированной позе.

Параметры `--out`, `--size` и `--skin` используют правила каталога, размера и семейства из раздела экспорта UV. Итоговая площадь карты должна укладываться в клиентский лимит 1 048 576 пикселей.

## Исходные файлы

| Файл | Назначение |
|---|---|
| `tools/matgen/src/Model.cpp` | Чтение `.mdl` и при необходимости связанного файла текстур. |
| `tools/matgen/src/manifests.cpp` | Встроенные манифесты программ. |
| `tools/matgen/src/Png.cpp` | Запись PNG через zlib. |
| `tools/matgen/src/uv_template.cpp` | Экспорт проволочной UV-развертки. |
| `tools/matgen/src/check.cpp` | Проверка документов, пресетов и метаданных изображений. |
| `tools/matgen/src/bake_edges.cpp` | Запекание пороговых карт износа. |
