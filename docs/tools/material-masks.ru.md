# Поставляемая коллекция изображений материалов

[Английская версия](material-masks.md) | [Руководство автора](../weapon-materials-authoring.ru.md)

Коллекция хранится в `assets/cstrike/materials/` и копируется вместе с ресурсами игры целью `BUILD_ALL`, если задан `NEXTCLIENT_INSTALL_DIR`. Материал ссылается на файлы относительно игрового каталога, например `materials/masks/wear/even.png`. В лимите изображений документа или пресета учитывается каждый различный файл, в том числе поставляемый с клиентом. Повторные ссылки на один файл учитываются один раз.

## Контракт совместимости

Опубликованные пути и содержимое изображений сохраняются, поскольку от них зависит вид материалов. Новые изображения добавляются под новыми именами. Изменения `make_masks.py` должны сохранять результат генерации существующих файлов коллекции.

## Состав

| Каталог внутри `materials/` | Содержимое | Обычный параметр |
|---|---|---|
| `masks/wear/` | Пороговые карты износа. | `uWearMap` |
| `masks/noise/` | Шумы нескольких частот. | `uWearMap`, `uPattern` |
| `masks/scratches/` | Тонкие и грубые, направленные и случайные царапины. | `uWearMap` |
| `masks/dirt/` | Грязь, подтеки и разводы. | `uWearMap` |
| `masks/reflect/` | Маски силы отражения. Белый цвет сохраняет отражение, черный подавляет. | `uReflectMask` |
| `surfaces/` | Обнажаемые поверхности металла, латуни и пластика. | `uUnderlay` |
| `matcaps/` | Изображения отражения, зависящего от направления взгляда. | `uSphereMap` |

## Требования к изображениям

Карта порогов износа темная там, где износ начинается, и светлая там, где покрытие сохраняется дольше. Маски отражения используют широкий диапазон контраста, чтобы различать блестящие и матовые участки. Изображения поверхностей задают цвет обнажаемого слоя.

Маски и изображения поверхностей бесшовно повторяются. Их шумовые поля периодические, а штрихи продолжаются на соседние копии, чтобы края стыковались при повторении текстуры. Изображения matcap показывают освещенную сферу и используют координаты, зависящие от направления взгляда. Размер всех изображений коллекции равен 512x512 пикселям. Пороговые маски серые, поскольку шейдер читает красный канал; изображения поверхностей и matcap цветные. Лимит площади изображения при загрузке равен 1 048 576 пикселям.

## Генерация

Выполните команду из корня репозитория с установленными Python, NumPy и Pillow:

```text
python tools/material_masks/make_masks.py
```

Скрипт использует отдельное фиксированное начальное значение генератора для каждого каталога. Сравните повторно созданные существующие файлы с отслеживаемыми изображениями, чтобы проверить неизменность содержимого.
