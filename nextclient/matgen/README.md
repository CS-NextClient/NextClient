# matgen

Утилита авторинга материалов оружия. Отдельный исполняемый файл, а не подкоманды чего-то в
`tools/`: он линкует `ncl_material` и `ncl_studio` как обычный потребитель пакетов снаружи
движка, и это же служит проверкой - если пакетом неудобно пользоваться отсюда, значит он
держит лишние связи.

Путь автора целиком - в [docs/weapon-materials-authoring.md](../../docs/weapon-materials-authoring.md).

## Сборка

```bash
cmake --build --preset ninja-local-debug --target matgen
```

Результат - `out/bin/<Config>/matgen.exe`. В игру он не ставится: это инструмент автора, а не
часть клиента.

## Подкоманды

### `matgen uv <model.mdl> [--out <dir>] [--size <pixels>] [--skin <family>]`

По каждому имени текстуры модели пишет PNG с её собственной проволочной развёрткой, чтобы
рисовать в двумерном редакторе и ничего не декомпилировать.

Шаблон сохраняет пропорции текстуры: для скина 256x512 получится 256x512, а не квадрат.
`--size` задаёт длинную сторону, короткая масштабируется.

Острова, лежащие вне текстуры, заворачиваются обратно потриугольно - туда, откуда их читает
сэмплер. Число завёрнутых треугольников печатается: это меняет то, на что автор смотрит.

### `matgen check <model.mat> [--game <dir>]`

Разбирает документ, проверяет против манифеста программы, которую он называет, и проверяет,
что каждая названная картинка существует, декодируется и укладывается в клиентский потолок
1024. Печатает то же, что напечатал бы клиент.

Пути внутри материала относительны мод-каталогу, то есть `--game`; по умолчанию - текущий,
так что запускать удобно из `cstrike/`. Код возврата 1, если есть проблемы.

Манифесты встроены сюда из тех же файлов, что встраивает движок. Разошедшаяся копия была бы
хуже отсутствия утилиты: она говорила бы «да» там, где клиент говорит «нет».

### `matgen bake edges <model.mdl> [--out <dir>] [--size <pixels>] [--skin <family>]`

Запекает карту порогов износа из геометрии модели: где поверхность выпукло изгибается, там
стирается первым. Единственная карта, которую поставляемая коллекция дать не может, потому
что она про рёбра конкретного ствола, а не про узор.

Кривизна меряется относительно распределения самой модели, а не относительно нуля: на
замкнутой поверхности почти каждый угол слегка выпуклый, и абсолютная мера дала бы почти
чёрную карту. Результат расширяется за края островов на несколько пикселей, иначе на швах
при фильтрации проступит фон.

Грубее блендеровской, но порог всё равно проходит через `smoothstep`.

## Устройство

| Файл | Что делает |
| --- | --- |
| `Model.cpp` | читает `.mdl`, при нужде подхватывает `<имя>T.mdl` с текстурами |
| `Manifests.cpp` | встроенные манифесты программ |
| `Png.cpp` | запись PNG через zlib; в дереве больше никто картинки не пишет |
| `UvTemplate.cpp` | `uv` |
| `Check.cpp` | `check` |
| `BakeEdges.cpp` | `bake edges` |
